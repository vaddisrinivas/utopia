# Support

Need help with Utopia:

- Read [README.md](./README.md) for the project model and setup.
- Read [CONTRIBUTING.md](./CONTRIBUTING.md) for change rules and required checks.
- Read [SECURITY.md](./SECURITY.md) for private vulnerability reporting and security boundaries.

## Where to ask

- Bug or behavior issue: open a GitHub issue with exact steps to reproduce.
- Enhancement request: open a GitHub issue with the user outcome and contract impact.
- Private security concern: use GitHub private vulnerability reporting.

## What to include

- Exact branch or version.
- Expected behavior.
- Actual behavior.
- Logs, screenshots, or file paths if they do not contain secrets or private data.
